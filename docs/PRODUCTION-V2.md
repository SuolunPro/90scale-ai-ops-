# 九十刻度4.0 运维巡检 v2.0

| 环节 | 正式入口或证据 |
| --- | --- |
| 主引擎 | 公开 `build-engine4.yml`，核对北京时间当日的实际运行及公开 main 快照。 |
| 数据采集 | 公开预测快照、同销售日档案和公开审计的在售证据。HTTP 响应和逐场字段覆盖独立取证。 |
| 自检补偿 | 公开 `public-refresh-audit.yml` 负责在售闸门、并发防重、必发补采及同步。回执目前仍写入私库，用只读凭据读取。 |
| 独立赛果 | Supabase 已核验公开投影、`supabase-settlement-publisher.yml` 和正式站。仅在有明确完赛证据时判断结算超时。 |
| 网站发布 | 固定公开 main 提交和 Pages 实际响应，核对 `latest` 与同销售日档案。 |
| 情报和研究 | 公开 FotMob 情报为影子采集。三核和旧独立复核文件供研究、历史查阅。 |
| 私库 | 公开工作流仍读取私库源码、交接产物和审计回执。私库 Actions 仅纳入额度审计。 |

`ops/daily.py --report-only` 输出中文日报。费用来自项目使用量账本，实际额度以账单为准。DeepSeek 只处理 v2 当前 WARN/FAIL，保留原预算、日限额和去重。空工单队列属于正常现象。

旧看门狗入口改为只读复验。受限人工恢复只能请求公开审计。恢复结论取决于对应销售日、赛号、目标字段和正式站实际发布。
